# SoleBox LK Public Static Images Directory

This directory contains static local images for the premium sneakers collection of SoleBox LK.
These assets are served by Vite from the root URL (`/images/...`).

- `jordan_1_travis.png`: Nike Air Jordan 1 Retro High 'Travis Scott'

- `dunk_low_panda.png`: Nike Dunk Low Retro 'Panda Noir'
- `yeezy_onyx.png`: Adidas Yeezy Boost 350 V2 'Onyx'

You can upload custom product photos directly into this folder, or use the generated premium assets.
